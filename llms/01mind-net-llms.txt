# 01Mind

> 01Mind is a Melbourne, Australia software and intelligence-system maker that runs an agent-facing "superstore" at 01mind.net: paid, per-call API services for autonomous agents — document rendering to real .docx/.xlsx, plaintext email sending, live legal-research answers, AI-written compliance reference packs, agent-economy venue intelligence and an on-demand safe tool-generation engine (Charon) — settled in USDC on Base through the x402 protocol, with no account required. The same catalogue is exposed as a REST API (OpenAPI 3.0.3), a remote MCP server and an A2A agent.

## How to call it

- No account or signup. Browsing, the free sandbox and a purchase all work anonymously; POST /keys (documented in prose, not in the OpenAPI) returns a free X-API-Key that carries five free documents a month.
- Payment is x402: call a paid route, receive a real HTTP 402 with payment requirements, retry with a signed payment attached. USDC on Base (eip155:8453). Paying accepts the Terms of Sale in force at the moment of payment.
- Through the REST routes you pay at POST /purchase/{listingId} and collect at POST /execute/{listingId} by proving control of the paying wallet: send walletAddress, signedAt (ISO 8601, within 10 minutes of the server clock) and an EIP-191 personal_sign of exactly "01Mind: collect <listingId> as <walletAddress> at <signedAt>". Each signature works once.
- POST /sandbox/execute/{listingId} is a free dry run that performs the identical validation as the paid call and reports what would be produced, without producing a file or consuming anything. A malformed payload is rejected before anything is consumed.
- Free, unauthenticated signals: GET /failure-modes (a five-entry failure-mode catalog), GET /latency-beacon, GET /activity, GET /listings/{listingId}/status, GET /document-templates, GET /venue-intelligence/quick-check, GET /venue/tasks, GET /research.

## Limits

- Email send: 20 per wallet per 24 hours; every send carries a server-added disclosure footer naming 01Mind and the sending wallet.
- Documents: 5 free per month per API key (resets on the 1st, UTC), then $0.25 each; request bodies up to 4 MB on /execute, larger returns 413.
- Gateway quota per key per window: 429 with Retry-After (per GET /failure-modes, FM-004).
